# 📊 Projetos e Atividades - Power BI

Este repositório contém os arquivos, bases de dados e projetos desenvolvidos ao longo do curso de **Power BI**. O objetivo é documentar o aprendizado prático em ETL, Power Query, modelagem de dados e criação de relatórios.

---

## 📁 Estrutura do Repositório

O repositório está organizado por módulos/aulas diárias:

* **`AULA 01 - 17082026`**
  * Introdução ao Power BI Desktop e primeiros passos com relatórios.
  * *Arquivos:* `Aula 01 Power BI.pbix`, `vendas (1).xlsx`

* **`AULA 02 - 18082026`**
  * Resolução da primeira atividade prática utilizando dados de produtos.
  * *Arquivos:* `Atividade 01 - Power BI.pbix`, `Tabela Produtos.xlsx`

* **`AULA 03 - 19082026`**
  * **Tratamento de Dados (Power Query):** Limpeza, transformação, combinação de tabelas e mesclagem de bases de dados.
  * *Arquivos:* `Atividade 03 - Tratamento de Dados PowerQuery.pbix`, `Explicacao PowerQuery.pbix`, bases em Excel (`Tabela Vendas.xlsx`, `Tabela Clientes (1).xlsx`, `BaseFuncionarios (2).xlsx`)

* **`AULA 04 - 20082026`**
  * **Modelagem de Dados:** Criação de relacionamentos entre tabelas (fato e dimensão) e conceitos de Star Schema.
  * *Arquivos:* Relatórios `.pbix` de atividades e explicações de modelagem; bases de dados categorizadas em subpastas de atividades.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Power BI Desktop** (Elaboração de Dashboards e Relatórios)
* **Power Query** (ETL - Extração, Transformação e Carga de dados)
* **Microsoft Excel** (Fonte de dados primária)
